## Particle Animation System

The particle system is the visual centerpiece of Wiloza, powered by particles.js library. It creates an animated network of interconnected particles that respond to user interaction.

### Configuration

The particle system is configured in `particula.js` with the following settings:

<CodeGroup>
```javascript particula.js
particlesJS("particles-js", {
  "particles": {
    "number": {
      "value": 80,
      "density": {
        "enable": true,
        "value_area": 800
      }
    },
    "color": {
      "value": "#ffffff"
    },
    "shape": {
      "type": "circle",
      "stroke": {
        "width": 0,
        "color": "#000000"
      }
    },
    "opacity": {
      "value": 0.5,
      "random": false
    },
    "size": {
      "value": 3,
      "random": true
    },
    "line_linked": {
      "enable": true,
      "distance": 150,
      "color": "#ffffff",
      "opacity": 0.4,
      "width": 1
    },
    "move": {
      "enable": true,
      "speed": 6,
      "direction": "none",
      "random": false,
      "straight": false,
      "out_mode": "out",
      "bounce": false
    }
  }
});
```

```css particula.css
#particles-js {
    position: fixed;
    width: 100%;
    height: 100%;
    background: radial-gradient(circle, #28a745 0%, #1a4d1a 100%);
    z-index: -1;
}
```
</CodeGroup>

### Particle Properties

<Accordion title="Number & Density">
  **Count:** 80 particles distributed across the screen
  
  **Density:** Enabled with value area of 800px² - particles automatically adjust based on screen size to maintain consistent visual density
  
  ```javascript
  "number": {
    "value": 80,
    "density": {
      "enable": true,
      "value_area": 800
    }
  }
  ```
</Accordion>

<Accordion title="Appearance">
  **Shape:** Circles with no stroke
  
  **Color:** White (`#ffffff`)
  
  **Opacity:** 50% (0.5) - creates a subtle, non-intrusive effect
  
  **Size:** 3px base with random variation for depth
  
  ```javascript
  "color": { "value": "#ffffff" },
  "opacity": { "value": 0.5, "random": false },
  "size": { "value": 3, "random": true }
  ```
</Accordion>

<Accordion title="Line Connections">
  **Enabled:** Particles connect when within range
  
  **Distance:** 150px maximum connection distance
  
  **Color:** White lines with 40% opacity
  
  **Width:** 1px thin lines
  
  ```javascript
  "line_linked": {
    "enable": true,
    "distance": 150,
    "color": "#ffffff",
    "opacity": 0.4,
    "width": 1
  }
  ```
</Accordion>

<Accordion title="Movement">
  **Speed:** 6 units - moderate, smooth movement
  
  **Direction:** None - particles move in random directions
  
  **Out Mode:** "out" - particles leave and re-enter from opposite side
  
  **Bounce:** Disabled - smooth continuous motion
  
  ```javascript
  "move": {
    "enable": true,
    "speed": 6,
    "direction": "none",
    "out_mode": "out",
    "bounce": false
  }
  ```
</Accordion>

### Interactive Modes

The particle system responds to user interaction with three modes:

<CodeGroup>
```javascript Hover - Repulse Mode
"interactivity": {
  "events": {
    "onhover": {
      "enable": true,
      "mode": "repulse"
    }
  },
  "modes": {
    "repulse": {
      "distance": 200,
      "duration": 0.4
    }
  }
}
```

```javascript Click - Push Mode
"interactivity": {
  "events": {
    "onclick": {
      "enable": true,
      "mode": "push"
    }
  },
  "modes": {
    "push": {
      "particles_nb": 4
    }
  }
}
```

```javascript Other Available Modes
"modes": {
  "grab": {
    "distance": 400,
    "line_linked": { "opacity": 1 }
  },
  "bubble": {
    "distance": 400,
    "size": 40,
    "duration": 2,
    "opacity": 8,
    "speed": 3
  }
}
```
</CodeGroup>

<Tip>
  The **repulse mode** on hover creates a dynamic effect where particles move away from the cursor, creating a 200px radius "bubble" around it.
</Tip>

### Performance Monitoring

Wiloza includes real-time performance tracking using Stats.js:

```javascript particula.js
stats = new Stats();
stats.setMode(0); // 0: fps, 1: ms, 2: mb
stats.domElement.style.position = 'absolute';
stats.domElement.style.left = '0px';
stats.domElement.style.top = '0px';
document.body.appendChild(stats.domElement);

// Count and display particle count
count_particles = document.querySelector('.js-count-particles');
update = function() {
    stats.begin();
    stats.end();
    if (window.pJSDom[0].pJS.particles && window.pJSDom[0].pJS.particles.array) {
        count_particles.innerText = window.pJSDom[0].pJS.particles.array.length;
    }
    requestAnimationFrame(update);
};
requestAnimationFrame(update);
```

<Note>
  The stats display shows FPS (frames per second) and the current number of active particles on screen.
</Note>

## Music Player

The integrated music player provides background audio with full user controls, featuring a modern glassmorphism design.

### HTML Structure

```html index.html
<div class="music-player">
    <audio id="miAudio" loop>
        <source src="music.mp3" type="audio/mpeg">
        Tu navegador no soporta el elemento de audio.
    </audio>
    
    <div class="controls">
        <button id="btnPlayPausa">
            <i id="icono" class="fas fa-play"></i>
        </button>
        <input type="range" id="controlVolumen" min="0" max="1" step="0.1" value="0.5">
    </div>
</div>
```

### Styling

The music player uses glassmorphism design principles:

<CodeGroup>
```css Container Styling
.music-player {
    margin-top: 20px;
    background: rgba(255, 255, 255, 0.1);
    padding: 15px;
    border-radius: 10px;
    backdrop-filter: blur(5px);
}
```

```css Controls Layout
.controls {
    display: flex;
    align-items: center;
    gap: 10px;
    justify-content: center;
}
```

```css Play/Pause Button
#btnPlayPausa {
    width: 50px;
    height: 50px;
    border-radius: 50%;
    border: none;
    background: white;
    cursor: pointer;
    display: flex;
    align-items: center;
    justify-content: center;
    font-size: 1.2rem;
    transition: transform 0.2s;
}

#btnPlayPausa:hover {
    transform: scale(1.1);
}
```
</CodeGroup>

### JavaScript Logic

The music player functionality is implemented with vanilla JavaScript:

<CodeGroup>
```javascript Element References
const audio = document.getElementById('miAudio');
const btnPlayPausa = document.getElementById('btnPlayPausa');
const icono = document.getElementById('icono');
const controlVolumen = document.getElementById('controlVolumen');
```

```javascript Play/Pause Toggle
btnPlayPausa.addEventListener('click', () => {
    if (audio.paused) {
        audio.play();
        icono.className = 'fas fa-pause';
    } else {
        audio.pause();
        icono.className = 'fas fa-play';
    }
});
```

```javascript Volume Control
controlVolumen.addEventListener('input', (e) => {
    audio.volume = e.target.value;
});
```
</CodeGroup>

```html index.html
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
```

### Meta Tag Breakdown

<Accordion title="Basic Properties">
  **Type:** `website` - Indicates this is a standard website page
  
  **URL:** `https://www.wiloza.com/` - Canonical URL for the page
  
  **Title:** Displayed as the headline in social previews
  
  **Description:** Shown as preview text below the title
</Accordion>

<Accordion title="Image Properties">
  **Image URL:** Full path to the preview image
  
  **Dimensions:** 1200x630 pixels - the optimal size for social media platforms
  
  **Why these dimensions?**
  - Facebook: Recommends 1200x630
  - Twitter: Supports 2:1 ratio
  - LinkedIn: Optimal at 1200x627
  
  <Tip>
    Using 1200x630 ensures your image displays correctly across all major social platforms without cropping.
  </Tip>
</Accordion>

## Analytics & Tracking

Wiloza integrates Google Analytics 4 (GA4) for comprehensive visitor tracking and behavior analysis.

### Implementation

The analytics script is loaded in the document head:

```html index.html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-4TYKW6F9T6"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-4TYKW6F9T6');
</script>
```

### What Gets Tracked

With the default GA4 configuration, the following events are automatically tracked:

<CardGroup cols={2}>
  <Card title="Page Views" icon="eye">
    Every time someone loads the landing page
  </Card>
  
  <Card title="User Demographics" icon="users">
    Location, device type, browser, screen resolution
  </Card>
  
  <Card title="Engagement" icon="clock">
    Time on page, scroll depth, active engagement time
  </Card>
  
  <Card title="Traffic Sources" icon="arrow-right-to-bracket">
    How visitors found the page (direct, referral, social, search)
  </Card>
</CardGroup>

### Tracked Interactions

GA4's enhanced measurement automatically captures:

- **Outbound clicks** - Links to Facebook and the store
- **File downloads** - If any download links are added
- **Video engagement** - Could track audio player interactions with custom events
- **Scroll tracking** - How far users scroll down the page

### Custom Event Tracking (Optional)

You can add custom event tracking for specific interactions:

```javascript Example: Track Music Player
// Track when user plays music
btnPlayPausa.addEventListener('click', () => {
    if (audio.paused) {
        audio.play();
        gtag('event', 'music_play', {
            'event_category': 'engagement',
            'event_label': 'Music Player'
        });
        icono.className = 'fas fa-pause';
    } else {
        audio.pause();
        gtag('event', 'music_pause', {
            'event_category': 'engagement',
            'event_label': 'Music Player'
        });
        icono.className = 'fas fa-play';
    }
});

// Track volume changes
controlVolumen.addEventListener('change', (e) => {
    gtag('event', 'volume_change', {
        'event_category': 'engagement',
        'event_label': 'Volume',
        'value': Math.round(e.target.value * 100)
    });
});
```

<Note>
  The measurement ID `G-4TYKW6F9T6` is specific to this project. When deploying your own version, replace it with your Google Analytics property ID.
</Note>
