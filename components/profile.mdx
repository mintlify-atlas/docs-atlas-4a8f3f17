## Overview

The profile section is the central focal point of the Wiloza landing page, featuring a centered layout with a profile image, stylized name heading, and integrated social media links. The section uses absolute positioning and transform techniques to achieve perfect centering over the particle background.

<Note>
The profile section sits above the particles background with `z-index: 1`, ensuring all content remains visible and interactive.
</Note>

## HTML Structure

The profile content is wrapped in a content overlay container:

```html
<div class="content-overlay">
  <a href="https://pengrafic.rdi.store/">
    <img src="wiloza.png" alt="Polos - Wiloza" class="profile-pic">
  </a>
  <h1>
    <a href="https://www.facebook.com/wiloza/">JL ZV</a>
  </h1>
  
  <!-- Music player follows -->
  <div class="music-player">
    <!-- ... -->
  </div>
</div>
```

<Warning>
Ensure all profile images have descriptive `alt` text for accessibility and SEO.
</Warning>

## Perfect Centering

The content overlay uses absolute positioning with transform for perfect centering:

```css
.content-overlay {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);  /* Perfect center alignment */
  text-align: center;
  width: 100%;
  z-index: 1;                        /* Above particles */
}
```

<Tip>
The `transform: translate(-50%, -50%)` technique centers elements regardless of their dimensions, making it ideal for responsive layouts.
</Tip>

## Profile Image Styling

The profile image is styled with auto-sizing and centered margins:

```css
.profile-img {
  width: 300px;              /* Fixed width */
  height: auto;              /* Maintain aspect ratio */
  display: block;
  margin: 0 auto 20px;       /* Center horizontally, 20px bottom margin */
}
```

<Note>
The CSS uses `.profile-img` class but the HTML uses `class="profile-pic"`. Ensure class names match in your implementation.
</Note>

## Heading Typography

The name heading uses custom typography with tight letter spacing:

```css
h1 {
  color: white;
  font-family: 'Inter', sans-serif;
  font-size: 3rem;
  font-weight: bold;
  letter-spacing: -1px;      /* Negative spacing pulls letters closer */
  text-transform: uppercase;
}

h1 a {
  color: white;
  text-decoration: none;     /* Remove underline from link */
}
```

The Inter font is imported from Google Fonts:

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap');
```

## Customization Guide

<Steps>
  <Step title="Adjust profile image size">
    Modify the width in CSS:
    
    ```css
    .profile-img {
      width: 250px;  /* Smaller image */
      /* or */
      width: 400px;  /* Larger image */
    }
    ```
  </Step>
  
  <Step title="Change font family">
    Import a different Google Font and update CSS:
    
    ```css
    @import url('https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap');
    
    h1 {
      font-family: 'Poppins', sans-serif;
    }
    ```
  </Step>
  
  <Step title="Modify heading size">
    Adjust the font-size property:
    
    ```css
    h1 {
      font-size: 4rem;    /* Larger */
      /* or */
      font-size: 2.5rem;  /* Smaller */
    }
    ```
  </Step>
  
  <Step title="Update social links">
    Replace URLs in the HTML:
    
    ```html
    <h1>
      <a href="https://twitter.com/yourusername">Your Name</a>
    </h1>
    ```
  </Step>
</Steps>

## Accessibility Best Practices

<Steps>
  <Step title="Add descriptive alt text">
    ```html
    <img src="wiloza.png" alt="Williams Lopez Zavaleta profile picture">
    ```
  </Step>
  
  <Step title="Ensure sufficient contrast">
    White text on the green gradient background provides good contrast (>4.5:1 ratio).
  </Step>
  
  <Step title="Make links keyboard accessible">
    All anchor tags are naturally keyboard focusable. Consider adding focus styles:
    
    ```css
    a:focus {
      outline: 2px solid white;
      outline-offset: 4px;
    }
    ```
  </Step>
  
  <Step title="Add semantic HTML">
    Use appropriate heading levels and landmark elements:
    
    ```html
    <main class="content-overlay">
      <header>
        <img src="wiloza.png" alt="Profile">
        <h1>JL ZV</h1>
      </header>
    </main>
    ```
  </Step>
</Steps>
