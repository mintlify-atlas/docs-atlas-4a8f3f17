## Overview

The Wiloza landing page features an interactive particle system powered by [particles.js](https://github.com/VincentGarreau/particles.js), creating a dynamic background with white particles that respond to user interactions. The particles are rendered on a radial gradient green background and provide hover and click effects.

<Note>
The particle system uses HTML5 Canvas for optimal performance and supports retina displays.
</Note>

## Installation

The particles.js library is loaded from a CDN in the HTML file:

```html
<script src="https://cdn.jsdelivr.net/particles.js/2.0.0/particles.min.js"></script>
```

## HTML Structure

The particles are rendered in a dedicated container that sits behind all other content:

```html
<!-- particles.js container -->
<div id="particles-js"></div>

<div class="content-overlay">
  <!-- Your content goes here -->
</div>
```

## Styling

The particles container is styled to cover the full viewport with a green radial gradient background:

```css
#particles-js {
  position: fixed;
  width: 100%;
  height: 100%;
  background: radial-gradient(circle, #28a745 0%, #1a4d1a 100%);
  z-index: -1; /* Sends particles to the background */
}
```

<Warning>
The `z-index: -1` is critical to ensure the particles stay behind the content overlay.
</Warning>

## Customization Options

<Accordion title="Particle Count">
Control the number of particles displayed:

```javascript
"number": {
  "value": 80,  // Number of particles
  "density": {
    "enable": true,
    "value_area": 800  // Particles per 800px²
  }
}
```
</Accordion>

<Accordion title="Particle Appearance">
Customize the look of individual particles:

```javascript
"color": { "value": "#ffffff" },  // White particles
"opacity": { "value": 0.5 },       // 50% opacity
"size": {
  "value": 3,        // Base size of 3px
  "random": true     // Randomize sizes
}
```
</Accordion>

<Accordion title="Connected Lines">
Particles are connected with lines when within range:

```javascript
"line_linked": {
  "enable": true,
  "distance": 150,      // Max distance for connections
  "color": "#ffffff",   // White lines
  "opacity": 0.4,       // 40% opacity
  "width": 1            // 1px line width
}
```
</Accordion>

<Accordion title="Movement Settings">
Control how particles move across the canvas:

```javascript
"move": {
  "enable": true,
  "speed": 6,            // Movement speed
  "direction": "none",   // Random directions
  "random": false,
  "straight": false,
  "out_mode": "out"     // Particles exit and re-enter
}
```
</Accordion>

## Performance Monitoring

The implementation includes stats.js for monitoring particle performance:

```javascript
var stats = new Stats();
stats.setMode(0);
stats.domElement.style.position = 'absolute';
stats.domElement.style.left = '0px';
stats.domElement.style.top = '0px';
document.body.appendChild(stats.domElement);

// Update particle count
count_particles = document.querySelector('.js-count-particles');
update = function() {
  stats.begin();
  stats.end();
  if (window.pJSDom[0].pJS.particles && window.pJSDom[0].pJS.particles.array) {
    count_particles.innerText = window.pJSDom[0].pJS.particles.array.length;
  }
  requestAnimationFrame(update);
};
requestAnimationFrame(update);
```

<Tip>
The stats display shows FPS and particle count in real-time, useful for debugging performance issues.
</Tip>

## Browser Compatibility

particles.js works in all modern browsers that support:
- HTML5 Canvas
- requestAnimationFrame API
- ES5 JavaScript

<Note>
Retina detection is disabled in this configuration (`"retina_detect": false`) for consistent cross-device performance.
</Note>

## Best Practices

<Steps>
  <Step title="Optimize particle count">
    Keep particle count between 50-100 for optimal performance on most devices.
  </Step>
  
  <Step title="Test interactivity">
    Ensure hover and click effects work smoothly without causing lag.
  </Step>
  
  <Step title="Consider mobile">
    Test on mobile devices and reduce particle count if needed for performance.
  </Step>
  
  <Step title="Monitor performance">
    Use the built-in stats display during development to track FPS.
  </Step>
