# Welcome to Wiloza

Wiloza is a sleek, interactive personal landing page featuring animated particle effects and an integrated music player. Built for Williams Lopez Zavaleta (JL ZV), this project showcases a modern web experience with dynamic visual effects and multimedia integration.

<Note>
  The name "Wiloza" is derived from Williams Lopez Zavaleta's name, creating a unique personal brand identity.
</Note>

## What is Wiloza?

Wiloza is a single-page personal landing page that combines aesthetic appeal with functionality. It features:

- **Interactive particle animations** powered by particles.js
- **Built-in music player** with play/pause and volume controls
- **Responsive design** that works across all devices
- **Analytics integration** with Google Analytics 4
- **Social media integration** with Open Graph meta tags
- **Modern gradient backgrounds** with radial color transitions

## Architecture Overview

The project follows a simple but effective three-layer architecture:

```
Wiloza Landing Page
├── index.html          # Structure and content
├── particula.css       # Styles and animations
└── particula.js        # Interactivity and particle config
```

### Component Structure

<Steps>
  <Step title="Particle Background Layer">
    A fixed-position canvas (`#particles-js`) that fills the viewport with animated particles. Uses a radial gradient from `#28a745` to `#1a4d1a` for a vibrant green aesthetic.
    
    ```html
    <div id="particles-js"></div>
    ```
  </Step>
  
  <Step title="Content Overlay">
    Centered content container with profile image, name, and music player. Uses absolute positioning with transform centering for perfect alignment.
    
    ```css
    .content-overlay {
        position: absolute;
        top: 50%;
        left: 50%;
        transform: translate(-50%, -50%);
        text-align: center;
        z-index: 1;
    }
    ```
  </Step>
  
  <Step title="Music Player Interface">
    Interactive audio controls with a glassmorphism design using backdrop filters and semi-transparent backgrounds.
  </Step>
</Steps>

## Visual Design

The landing page features a distinctive visual identity:

**Color Scheme:**
- Primary: Green radial gradient (`#28a745` → `#1a4d1a`)
- Text: White with Inter font family
- Accents: White particles with 50% opacity

**Typography:**
```css
h1 {
    font-family: 'Inter', sans-serif;
    font-size: 3rem;
    font-weight: bold;
    letter-spacing: -1px;
    text-transform: uppercase;
}
```

**Effects:**
- Glassmorphism music player with `backdrop-filter: blur(5px)`
- Hover animations on play button with `transform: scale(1.1)`
- Connected particle network with interactive repulsion on hover

</Warning>

## Performance

The page includes Stats.js for real-time performance monitoring:

```javascript
stats = new Stats();
stats.setMode(0); // FPS mode
stats.domElement.style.position = 'absolute';
stats.domElement.style.left = '0px';
stats.domElement.style.top = '0px';
document.body.appendChild(stats.domElement);
```

Particle count is dynamically tracked and displayed:
- Default: 80 particles
- Density-based: Adjusts based on viewport size (800px² value area)
- Interactive: Adds 4 particles on click, removes 2 on remove mode
