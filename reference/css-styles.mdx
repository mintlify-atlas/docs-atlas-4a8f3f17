## Overview

The Wiloza landing page uses a combination of reset styles, gradient backgrounds, and glassmorphism effects to create a modern, visually appealing interface. The CSS leverages custom Google Fonts, radial gradients, and backdrop filters for a polished look.

## Font Import

The page uses the Inter font family from Google Fonts:

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap');
```

<Note>
Inter is loaded with two weights: 400 (regular) and 700 (bold), optimized with `display=swap` to prevent invisible text during font loading.
</Note>

## Reset Styles

Basic reset styles normalize browser defaults:

```css
/* ---- reset ---- */
body {
```

## Content Overlay

The content overlay centers all visible content using absolute positioning and transforms:

```css
.content-overlay {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  text-align: center;
  width: 100%;
  z-index: 1;
}
```

<Accordion title="Centering Technique Explained">
  This is a classic CSS centering technique:
  
  1. `position: absolute` removes the element from normal flow
  2. `top: 50%` and `left: 50%` position the top-left corner at the viewport center
  3. `transform: translate(-50%, -50%)` shifts the element back by half its own dimensions
  4. Result: Perfect centering regardless of content size
</Accordion>

## Music Player Glassmorphism

The music player uses modern glassmorphism effects:

```css
.music-player {
  margin-top: 20px;
  background: rgba(255, 255, 255, 0.1);
  padding: 15px;
  border-radius: 10px;
  backdrop-filter: blur(5px);
}
```

### Glassmorphism Breakdown

| Property | Value | Effect |
|----------|-------|--------|
| `background` | `rgba(255, 255, 255, 0.1)` | Semi-transparent white (10% opacity) |
| `backdrop-filter` | `blur(5px)` | Blurs content behind the element |
| `border-radius` | `10px` | Rounded corners for modern look |
| `padding` | `15px` | Internal spacing for content |

<Tip>
The combination of low-opacity background and backdrop-filter blur creates the signature "frosted glass" effect that's trending in modern UI design.
</Tip>

### Backdrop Filter Fallback

```css
.music-player {
  background: rgba(255, 255, 255, 0.2); /* Slightly more opaque for non-blur browsers */
  backdrop-filter: blur(5px);
}

/* Fallback for unsupported browsers */
@supports not (backdrop-filter: blur(5px)) {
  .music-player {
    background: rgba(255, 255, 255, 0.3);
  }
}
```
