## Personal Information

### Update Name and Title

Edit the `<h1>` tag in `index.html` (line 45):

```html
<h1><a href="https://www.facebook.com/wiloza/">JL ZV </a></h1>
```

**Customize it:**

```html
<h1><a href="https://yourwebsite.com/">Your Name</a></h1>
```

<Tip>
  The link wraps the entire name, so clicking your name will navigate to the URL you specify.
</Tip>

### Change Profile Image

Replace the profile image on line 44 of `index.html`:

```html
<a href="https://pengrafic.rdi.store/">
  <img src="wiloza.png" alt="Polos - Wiloza" class="profile-pic">
</a>
```

**To customize:**

<Steps>
  <Step title="Prepare Your Image">
    - Recommended size: 300x300 pixels or larger
    - Format: PNG with transparency works best
    - Name your file (e.g., `profile.png`)
  </Step>

  <Step title="Update HTML">
    ```html
    <a href="https://yourportfolio.com/">
      <img src="profile.png" alt="Your Name" class="profile-pic">
    </a>
    ```
  </Step>

  <Step title="Adjust Size (Optional)">
    Modify the image width in `particula.css` (line 27):
    ```css
    .profile-img {
      width: 300px; /* Adjust this value */
      height: auto;
      display: block;
      margin: 0 auto 20px;
    }
    ```
  </Step>
</Steps>

<Note>
  The current HTML uses class `profile-pic` but the CSS defines `.profile-img`. Make sure your image has the class that matches your CSS rules.
</Note>

### Particle Colors

Change particle and line colors in `particula.js` (line 24):

**Current configuration:**
```javascript
"particles": {
  "color": {"value": "#ffffff"},  // Particle color
  "line_linked": {
    "enable": true,
    "distance": 150,
    "color": "#ffffff",  // Line color
    "opacity": 0.4,
    "width": 1
  }
}
```

**Try different colors:**
```javascript
// Golden particles
"color": {"value": "#ffd700"}

// Multi-color particles (random)
"color": {"value": ["#ffffff", "#ff6b6b", "#4ecdc4", "#ffe66d"]}
```

## Typography

### Change Font Family

The page currently uses the Inter font from Google Fonts. To change it:

<Steps>
  <Step title="Choose a New Font">
    Browse [Google Fonts](https://fonts.google.com) and select a font.
  </Step>

  <Step title="Update Import">
    In `particula.css` (line 2), replace the font import:
    ```css
    @import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap');
    ```
  </Step>

  <Step title="Apply Font">
    Update the font-family in the h1 styles:
    ```css
    h1 {
        font-family: 'Roboto', sans-serif;
    }
    ```
  </Step>
</Steps>

### Adjust Text Size

Modify font size in `particula.css` (line 37):

```css
h1 {
    font-size: 3rem;  /* Default: 3rem (48px) */
}
```

**Responsive sizing:**
```css
h1 {
    font-size: 3rem;
}

@media (max-width: 768px) {
    h1 {
        font-size: 2rem;  /* Smaller on mobile */
    }
}
```

### Letter Spacing

Control letter spacing in `particula.css` (line 39):

```css
h1 {
    letter-spacing: -1px;  /* Negative = tighter, positive = wider */
}
```

## Background Music

### Replace Music File

<Steps>
  <Step title="Prepare Your Audio">
    - Format: MP3 (best compatibility)
    - Recommended: Compressed to 128-192 kbps
    - Keep file size under 5MB for faster loading
  </Step>

  <Step title="Replace File">
    Place your MP3 file in the project root and name it `music.mp3`, or update the reference in `index.html` (line 49):
    ```html
    <audio id="miAudio" loop>
        <source src="your-music.mp3" type="audio/mpeg">
        Tu navegador no soporta el elemento de audio.
    </audio>
    ```
  </Step>

  <Step title="Update Fallback Text (Optional)">
    Change the Spanish text to English or your preferred language:
    ```html
    <audio id="miAudio" loop>
        <source src="music.mp3" type="audio/mpeg">
        Your browser does not support the audio element.
    </audio>
    ```
  </Step>
</Steps>

<Note>
  The `loop` attribute makes the music repeat continuously. Remove it if you want the music to play only once.
</Note>

### Adjust Default Volume

Modify the initial volume in `index.html` (line 57):

```html
<input type="range" id="controlVolumen" min="0" max="1" step="0.1" value="0.5">
```

**Volume levels:**
- `value="0.5"` - 50% volume (default)
- `value="0.3"` - 30% volume (quieter)
- `value="0.8"` - 80% volume (louder)
- `value="1.0"` - 100% volume (maximum)

## Particle Effects

### Adjust Particle Count

Modify density in `particula.js` (line 24):

```javascript
"particles": {
  "number": {
    "value": 80,  // Number of particles
    "density": {
      "enable": true,
      "value_area": 800  // Density per area
    }
  }
}
```

**Recommendations:**
- **Light:** 40-60 particles
- **Medium:** 80-100 particles (default)
- **Heavy:** 120-150 particles
- **Extreme:** 200+ particles (may impact performance)

### Particle Size

Change size parameters:

```javascript
"size": {
  "value": 3,       // Base size
  "random": true,   // Vary sizes
  "anim": {
    "enable": false,  // Enable size animation
    "speed": 40,
    "size_min": 0.1,
    "sync": false
  }
}
```

**Enable pulsing particles:**
```javascript
"size": {
  "value": 4,
  "random": true,
  "anim": {
    "enable": true,   // Particles grow and shrink
    "speed": 40,
    "size_min": 0.1,
    "sync": false
  }
}
```

### Particle Speed

Adjust movement speed:

```javascript
"move": {
  "enable": true,
  "speed": 6,  // Movement speed (default: 6)
  "direction": "none",
  "random": false,
  "straight": false,
  "out_mode": "out",
  "bounce": false
}
```

**Speed presets:**
- **Slow:** `speed: 2`
- **Medium:** `speed: 6` (default)
- **Fast:** `speed: 10`

### Connection Lines

Customize the lines connecting particles:

```javascript
"line_linked": {
  "enable": true,    // Show/hide lines
  "distance": 150,   // Max distance to draw lines
  "color": "#ffffff",
  "opacity": 0.4,    // Line transparency
  "width": 1         // Line thickness
}
```

**Disable lines completely:**
```javascript
"line_linked": {
  "enable": false
}
```

**Thicker, more visible lines:**
```javascript
"line_linked": {
  "enable": true,
  "distance": 200,
  "color": "#ffffff",
  "opacity": 0.7,
  "width": 2
}
```

### Interaction Effects

Customize mouse interactions in `particula.js`:

**Hover effect (repulse):**
```javascript
"interactivity": {
  "events": {
    "onhover": {
      "enable": true,
      "mode": "repulse"  // Options: "grab", "bubble", "repulse"
    }
  },
  "modes": {
    "repulse": {
      "distance": 200,   // Repulse radius
      "duration": 0.4
    }
  }
}
```

**Click effect (push):**
```javascript
"onclick": {
  "enable": true,
  "mode": "push"  // Add particles on click
},
"modes": {
  "push": {
    "particles_nb": 4  // Particles added per click
  }
}
```

<Tip>
  Try different interaction modes:
  - **grab**: Draws lines to particles near cursor
  - **bubble**: Particles grow when cursor is near
  - **repulse**: Particles move away from cursor
  - **push**: Adds particles on click
  - **remove**: Removes particles on click
</Tip>
