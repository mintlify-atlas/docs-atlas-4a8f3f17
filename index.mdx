## Welcome to Wiloza

Wiloza is a modern, interactive personal landing page built for Williams Lopez Zavaleta. It combines elegant visual effects with an immersive user experience, featuring animated particle backgrounds and an integrated music player.

## Key Features

<AccordionGroup>
  <Accordion title="Animated Particle Background" icon="sparkles">
    Interactive particle.js integration with hover and click effects that respond to user interaction. White particles float across a gradient green background with dynamic movement patterns.
  </Accordion>
  
  <Accordion title="Music Player" icon="music">
    Built-in audio player with play/pause controls and adjustable volume slider. Supports looping background music with elegant glassmorphic UI controls.
  </Accordion>
  
  <Accordion title="Responsive Design" icon="mobile">
    Fully responsive layout that centers content perfectly on any screen size. Profile image, heading, and controls adapt seamlessly to different viewports.
  </Accordion>
  
  <Accordion title="Social Integration" icon="share-nodes">
    Direct links to Facebook profile and external store, making it easy for visitors to connect and explore your products.
  </Accordion>
</AccordionGroup>

## Built With

The landing page uses modern web technologies:

- **particles.js** - For the animated particle background
- **Font Awesome 6** - For music player icons
- **Google Analytics** - For visitor tracking
- **Vanilla JavaScript** - For music player controls
- **Custom CSS** - For styling and glassmorphic effects

## Get Started

<Steps>
  <Step title="Download the Files">
    Clone or download the repository containing all HTML, CSS, and JavaScript files
  </Step>
  <Step title="Customize Content">
    Update the profile image, links, and text to match your personal brand
  </Step>
  <Step title="Add Your Music">
    Replace `music.mp3` with your own audio file for the background player
  </Step>
  <Step title="Deploy">
    Upload to your web hosting service or deploy to platforms like GitHub Pages, Netlify, or Vercel
  </Step>
</Steps>
